# MeshCentral Remote Access Agent Masquerading as Cloud Services

## Description

Detects unauthorized deployment of MeshCentral remote management agents used as command-and-control (C2) infrastructure, specifically instances where agents are disguised with cloud-service-themed filenames (e.g., `meshagent64-azure-ops.exe`, `meshagent32-azure-ops.exe`) or connect to attacker-controlled self-hosted MeshCentral servers rather than legitimate corporate-managed deployments.

MeshCentral is a free, open-source remote device management platform. While legitimate in enterprise IT contexts, it has been increasingly abused by threat actors as a C2 alternative because it:
- Communicates over WebSocket/HTTPS (port 443), blending with normal web traffic
- Supports full remote shell, file transfer, and screen control
- Can be self-hosted with a custom domain and auto-provisioned TLS certificate
- Generates agents with arbitrary custom names to impersonate trusted software

ShinyHunters (UNC6240) deployed MeshCentral v1.1.59 in their CVE-2026-35273 Oracle PeopleSoft exploitation campaign (May–June 2026), using agents named `meshagent64-azure-ops.exe` connecting to `azurenetfiles.net` to mimic Azure infrastructure.

**False positives:** Organizations with legitimate MeshCentral deployments for endpoint management. Tune by whitelisting known MeshCentral server FQDNs and excluding processes that connect to your organization's managed MeshCentral server. Process names containing `azure-ops`, `v2.exe`, or other non-standard suffixes are not generated by default MeshCentral installs and should always be investigated.

## Splunk Detection Query

```spl
| tstats `security_content_summariesonly` count min(_time) as firstTime max(_time) as lastTime
from datamodel=Endpoint.Processes
where Processes.process_name IN ("meshagent","meshagent.exe","MeshAgent.exe",
                                  "meshagent32-azure-ops.exe","meshagent64-azure-ops.exe",
                                  "meshagent64-v2.exe","meshagent32-v2.exe")
  OR (Processes.process_name IN ("meshagent.exe","MeshAgent.exe")
      AND Processes.process!="*mesh.meshcentral.com*")
by Processes.dest Processes.user Processes.parent_process_name
   Processes.process_name Processes.process Processes.process_id
| `drop_dm_object_name(Processes)`
| `security_content_ctime(firstTime)`
| `security_content_ctime(lastTime)`
| eval risk_score=case(
    match(process_name, "azure-ops|azure-svc|v2\\.exe"), 95,
    match(process, "azurenetfiles|azurestaticprovider|azurecdnprovider|azureapps"), 95,
    NOT match(process, "your-legitimate-meshcentral-fqdn"), 80,
    1=1, 75)
| where risk_score >= 75
| table firstTime lastTime dest user parent_process_name process_name process risk_score
```

```spl
| tstats `security_content_summariesonly` count min(_time) as firstTime max(_time) as lastTime
from datamodel=Network_Traffic.All_Traffic
where All_Traffic.dest_port=443
  AND All_Traffic.process IN ("meshagent","meshagent.exe","MeshAgent.exe",
                               "meshagent32-azure-ops.exe","meshagent64-azure-ops.exe",
                               "meshagent64-v2.exe")
by All_Traffic.src All_Traffic.dest All_Traffic.dest_port All_Traffic.process
   All_Traffic.bytes_out All_Traffic.bytes_in
| `drop_dm_object_name(All_Traffic)`
| `security_content_ctime(firstTime)`
| `security_content_ctime(lastTime)`
| lookup threat_intel_ips dest OUTPUT threat_context
| eval risk_score=case(
    isnotnull(threat_context), 95,
    match(process, "azure-ops|v2\\.exe"), 90,
    1=1, 75)
| where risk_score >= 75
| table firstTime lastTime src dest dest_port process bytes_out bytes_in threat_context risk_score
```

```spl
| tstats `security_content_summariesonly` count min(_time) as firstTime max(_time) as lastTime
from datamodel=Network_Resolution.DNS
where DNS.query IN ("azurenetfiles.net","azurenetfiles.com","azurestaticprovider.net",
                    "azurecdnprovider.net","azureappsconfig.net")
by DNS.src DNS.query DNS.answer
| `drop_dm_object_name(DNS)`
| `security_content_ctime(firstTime)`
| `security_content_ctime(lastTime)`
| eval risk_score=100
| table firstTime lastTime src query answer risk_score
```

## Risk Score Logic

| Condition | Score | Rationale |
|-----------|-------|-----------|
| MeshCentral agent process with `azure-ops` or cloud-masquerade suffix | 95 | No legitimate deployment generates agents with these names; specific ShinyHunters IOC pattern |
| MeshCentral process connecting to `azurenetfiles.net` or similar typosquat | 95 | Confirmed ShinyHunters C2 domain; direct IOC hit |
| DNS query for `azurenetfiles.net` | 100 | Confirmed ShinyHunters C2 domain |
| Unlisted MeshCentral process (not connecting to corporate FQDN) | 80 | Shadow IT or unauthorized deployment requiring investigation |
| MeshCentral process present with known threat-intel IP destination | 95 | IOC match against threat intel feed |
