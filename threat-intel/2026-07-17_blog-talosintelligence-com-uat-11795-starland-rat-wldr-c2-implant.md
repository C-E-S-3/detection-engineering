## 3. Malware & Tools

### Starland RAT

A Python-based remote access trojan compiled into a self-contained Windows executable using PyInstaller or similar. Starland RAT establishes outbound HTTP C2 to actor-controlled domains and VPS servers. It implements a blockchain-based C2 fallback: when primary HTTP endpoints are unreachable, the RAT polls a Polygon blockchain smart contract for instructions encoded in contract state. This fallback mechanism makes C2 resilient to domain takedowns, as the Polygon contract address is hardcoded and cannot be sinkholed through conventional DNS intervention. Starland RAT supports remote command execution, file transfer, and secondary payload delivery (CastleStealer, WLDR, Remcos RAT).

### WLDR (Windows Loader) Implant

A bespoke PowerShell memory-resident implant injected by Starland RAT into a legitimate process context. WLDR provides a secondary C2 channel with capabilities including keylogging, screenshot capture, and credential harvesting. The implant is designed to be fileless — it runs entirely in memory and is not written to disk, complicating forensic recovery. Talos describes WLDR as a "bespoke" implant custom-developed for UAT-11795, with no observed code overlap with public malware families.

### CastleStealer

An infostealer payload deployed by Starland RAT as a secondary stage. CastleStealer harvests credentials stored in browsers, credential managers, and other password stores.

### Remcos RAT

A commercially available remote access tool used by UAT-11795 for interactive remote access and as a fallback persistence mechanism.

### Delivery mechanism

UAT-11795 uses SEO poisoning to promote fake download pages for popular utilities (MobaXterm, Webex, FaceIt, DBeaver, Zoom) in search engine results. When a victim downloads and executes the fake installer, it silently runs the Starland RAT in the background while also executing the legitimate installer to create the appearance of a normal installation. The actor also distributes installer links via direct messaging channels.

## 4. Threat Actor / Campaign Attribution

**Actor:** UAT-11795 (Cisco Talos internal designation)

**Motivation:** Financially motivated; likely targeting credentials, cryptocurrency, and financial account access

**Origin:** Russian-speaking threat actor (assessed based on forum activity and operational patterns)

**Activity window:** Active since at least June 2025; campaign observed through July 2026

**Target geography:** United States and Europe

**Blockchain C2 innovation:** The use of a Polygon blockchain smart contract as a C2 fallback channel is a notable TTP escalation. It follows similar blockchain-based C2 patterns observed in EtherHiding (used by WeedHack MaaS) and other commodity malware, but the Polygon contract represents a higher-effort implementation. The contract address is hardcoded in the RAT binary; because it is not a DNS record, it cannot be sinkholed, and because transactions on a public blockchain are irreversible, any instructions published to the contract state persist indefinitely.

**Operator notifications:** The actor uses a Telegram bot for real-time notifications when a new victim system is compromised, consistent with operational patterns seen in commodity MaaS (Malware-as-a-Service) operations.

## 5. Splunk Detection Searches

### Query 1: Trojanized Installer Spawning Python (Starland RAT Execution)

```spl
| tstats `security_content_summariesonly` count min(_time) as firstTime max(_time) as lastTime
from datamodel=Endpoint.Processes
where Processes.process_name IN ("python.exe", "python3.exe", "pythonw.exe")
  AND (Processes.parent_process IN ("*MobaXterm*", "*WebEx_Client*", "*FaceitInstaller*",
    "*dbeaver-ce-windows-x86_64*", "*Zoom*Installer*")
  OR Processes.parent_process_name IN ("MobaXterm_v26.1.exe", "WebEx_Client.exe",
    "FaceitInstaller_x64.exe", "dbeaver-ce-windows-x86_64.exe"))
by Processes.dest Processes.user Processes.parent_process_name
   Processes.process_name Processes.process Processes.process_id
| `drop_dm_object_name(Processes)`
| `security_content_ctime(firstTime)`
| `security_content_ctime(lastTime)`
| eval risk_score=90
| table firstTime lastTime dest user parent_process_name process_name process risk_score
```

## 6. Executive Summary

On July 17, 2026, Cisco Talos published research on UAT-11795, a financially motivated, Russian-speaking threat actor active since June 2025 that targets victims in the United States and Europe. The actor distributes trojanized versions of popular software installers — MobaXterm, Webex Client, FaceIt, DBeaver Community Edition, and Zoom — through SEO-poisoned download pages and direct messaging. When a victim executes the fake installer, it silently deploys Starland RAT (a Python-compiled backdoor) alongside the legitimate software. Starland RAT communicates with actor-controlled C2 over HTTP to six identified VPS servers and eight registered domains; when those endpoints are unreachable, it falls back to polling a Polygon blockchain smart contract for instructions. This blockchain C2 fallback is not sinkholable through DNS intervention and represents a meaningful resilience improvement over domain-based C2 alone. After initial access, Starland RAT injects WLDR — a bespoke memory-resident PowerShell agent — for keylogging, screenshot capture, and credential harvesting. Secondary payloads include CastleStealer and Remcos RAT. Operator notifications arrive via a Telegram bot. Talos released 28 SHA256 hashes, 8 C2 domains, and 6 C2 IPs; all are new IOCs with no prior tracking in this repository.
